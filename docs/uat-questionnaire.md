# RemitTrend PH: user acceptance test

Thank you for helping us test RemitTrend PH, a dashboard that shows trends and forecasts of the money overseas Filipinos send home. This takes about 20 minutes.

There are no wrong answers. We are testing the system, not you. If something is confusing, that is what we need to know.

Do not hand this section to the respondent.

**Before the session.** Start the app and open Overview. Use the same computer and browser for every respondent. Do not explain the pages beforehand.

**Scoring.** Report the mean of each statement and of each of the three groups. A common reading of a five-point mean: 4.21–5.00 strongly agree, 3.41–4.20 agree, 2.61–3.40 neutral, 1.81–2.60 disagree, 1.00–1.80 strongly disagree.
